# MVCApi
Angular version - 13.1.0, Dotnet version - 6.0  
# Uruchomienie aplikacji
Backend - W folderze MVCApi\MVCApi uruchomić polecenie dotnet run. Trzeba to zrobić dwa razy, gdyż baza danych tego wymaga.  
Frontend - W folderze MVCApi\MVCApi.AngularClient uruchomić polecenie bun install aby zainstalować wszystkie zależności, po czym uruchomić poleceniem bun run start.  
# Uruchomienie testów
bun run test - testy jednostkowe front-end  
bunx playwright test - testy e2e  
dotnet test - testy jednostkowe backend
